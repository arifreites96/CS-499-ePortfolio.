## Travlr Getaways

### Enhancement One: Software Design and Engineering

#### Artifact Description

The artifact I selected for the Software Design and Engineering enhancement is the Travlr Getaways full-stack web application that I originally developed in CS 465: Full Stack Development I. The application uses the MEAN stack (MongoDB, Express, Angular, and Node.js) to allow users to browse travel packages and provides an administrative interface for managing trip information.

This artifact demonstrates both front-end and back-end development and represents one of the most comprehensive software projects I completed during my degree program.

## Justification for Inclusion

I selected this artifact because it best demonstrates my software engineering knowledge and my ability to design, develop, and improve a complete application. Unlike smaller programming assignments, Travlr Getaways required me to work across multiple technologies while following software engineering principles such as modular design, separation of concerns, and client-server architecture.

For this enhancement, I focused on improving the software design rather than simply adding new features. I refactored portions of the code to improve readability and maintainability, organized components more effectively, improved validation, cleaned up repeated code, and strengthened error handling.

These enhancements make the application easier to maintain, easier to extend with future features, and more reliable for users. The improvements also demonstrate my growth since originally completing the course because I can now recognize opportunities to improve code quality using industry best practices.

## Course Outcomes

This enhancement demonstrates progress toward several Computer Science program outcomes:

- Designing and evaluating computing solutions using software engineering principles and standards.
- Using professional software engineering techniques, tools, and best practices to implement computing solutions.
- Developing a security mindset through improved validation, reduced vulnerabilities, and maintainable code.

Compared to my original enhancement plan developed during the code review, my overall objectives remained the same. However, while working through the project, I identified additional opportunities to improve code organization and error handling that further strengthened the application's overall design.

## Reflection

Enhancing this artifact helped me realize how much my software engineering skills have developed throughout the Computer Science program. When I originally created Travlr Getaways, my primary focus was making the application function correctly.

During this enhancement, I approached the project from a professional software engineering perspective by evaluating maintainability, readability, modularity, scalability, and security.

One of the biggest challenges was modifying existing code without introducing new bugs. Refactoring an existing application requires understanding how multiple components interact, which reinforced the importance of planning changes carefully and testing throughout the development process.

I also gained a greater appreciation for writing clean, organized code because it makes future enhancements significantly easier.

Overall, this enhancement demonstrates not only the functionality of the application but also my growth as a software developer. It reflects my ability to evaluate existing software, identify opportunities for improvement, implement professional software engineering practices, and produce higher-quality, more maintainable code.
