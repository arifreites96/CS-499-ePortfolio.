## Professional Self-Assessment

Completing the Bachelor of Science in Computer Science program has allowed me to develop from a student learning individual programming concepts into a computer science professional who understands how those concepts work together to create reliable, efficient, and secure computing solutions. Throughout the program, I have developed skills in software engineering, programming, databases, algorithms and data structures, security, testing, full-stack development, and emerging technologies.

One of my greatest areas of growth has been problem-solving. Earlier in the program, I often approached programming assignments by focusing primarily on whether the program produced the expected result. As I progressed through the Computer Science program, I learned that professional software development requires considering much more than functionality. Code must also be readable, maintainable, efficient, scalable, testable, and secure.

### Collaboration and Communication

The Computer Science program strengthened my understanding of collaboration and communication in technical environments. Developers must understand requirements from stakeholders, communicate technical decisions clearly, incorporate feedback, document their work, and design solutions that other developers can understand and maintain.

Throughout my coursework, I practiced communicating technical concepts through project documentation, discussions, presentations, diagrams, code comments, and written analyses. My capstone code review further developed this skill by requiring me to evaluate existing software and communicate proposed improvements to an audience.

I also learned the importance of incorporating feedback into the development process. Instructor feedback throughout the program encouraged me to revisit implementations, identify weaknesses, troubleshoot problems, and improve my work rather than viewing the first functioning implementation as the finished product.

### Data Structures and Algorithms

My coursework in algorithms and data structures strengthened my ability to consider how information should be organized and processed rather than simply stored. I learned to evaluate data structures based on the requirements of a particular problem and consider efficiency, maintainability, and scalability when designing computing solutions.

I also developed a greater understanding of algorithmic efficiency and design trade-offs. A solution that works correctly with a small amount of data may not remain appropriate as an application grows. Understanding algorithms and data structures allows me to evaluate these decisions and select solutions based on both current requirements and potential future needs.

### Software Engineering and Databases

Software engineering has been one of the most comprehensive areas of my development throughout the program. My coursework exposed me to multiple programming languages, development environments, architectures, testing practices, and software-development methodologies.

I learned principles such as modular design, separation of concerns, client-server architecture, input validation, error handling, debugging, and maintainable code organization.

Full-stack development expanded this knowledge by requiring me to understand how multiple layers of an application communicate. Working with technologies such as Angular, Node.js, Express, RESTful APIs, MongoDB, and Mongoose helped me understand the relationship between frontend interfaces, backend application logic, APIs, and persistent data.

Database coursework and application development also changed the way I view data management. A database is not simply a location where information is stored. Database structure influences the reliability, performance, scalability, maintainability, and security of an application.

### Security Mindset

Security became increasingly important as I progressed through the Computer Science program. Coursework in secure coding taught me that security should be considered throughout the software-development lifecycle rather than added after an application has already been developed.

I gained experience evaluating software for vulnerabilities, performing static code analysis, considering input validation, examining insecure coding practices, and identifying opportunities to reduce risk.

My work in reverse software engineering further expanded my ability to analyze existing software rather than only create new applications. Together, these experiences taught me to consider how user input is validated, how data is accessed, how errors are handled, and how an attacker could potentially misuse application functionality.

### Professional Goals

The variety of projects completed throughout the program helped me better understand my strengths and professional interests. While programming remains an important part of my technical foundation, I have become particularly interested in roles involving data analysis and quality assurance.

These areas allow me to combine technical knowledge with problem-solving, analysis, attention to detail, and an understanding of how software and data should behave.

The program also taught me that working in computer science requires continuous learning. Technologies, programming languages, security threats, and industry practices continue to evolve. I have developed the ability to learn unfamiliar tools, troubleshoot problems, research solutions, and adapt existing knowledge to new situations.
