## Travlr Getaways

### Enhancement Three: Databases

#### Artifact Description

The artifact selected for this enhancement is the Travlr Getaways full-stack travel management application that I originally developed in CS 465: Full Stack Development I.

The application uses the MEAN stack (MongoDB, Express.js, Angular, and Node.js) to allow users to browse travel packages while administrators manage trips through a secure interface.

The application stores trip information in a MongoDB database using Mongoose models and provides RESTful API endpoints for creating, reading, updating, and deleting travel packages.

## Justification for Inclusion

I selected this artifact because it demonstrates practical experience designing and working with a NoSQL database in a modern web application.

Unlike simple classroom exercises, this project integrates the database with both the backend API and frontend interface, making it a realistic example of full-stack software development.

The database portion demonstrates several important skills:

- MongoDB database design
- Mongoose schema development
- CRUD operations
- REST API integration
- Data validation
- Secure database access through authenticated routes

To strengthen this artifact for my ePortfolio, I enhanced the database implementation by improving schema validation, strengthening error handling during CRUD operations, organizing database queries more efficiently, and improving the maintainability of the backend code.

These enhancements demonstrate a stronger understanding of database management and professional software development practices.

## Course Outcomes

This enhancement demonstrates my ability to use well-founded and innovative techniques, skills, and tools in computing practices to implement computing solutions that deliver value and accomplish industry-specific goals.

By improving the database layer, I demonstrated a stronger understanding of data management, backend architecture, and modern database technologies.

The enhancement also supports the security outcome by improving data validation and reducing opportunities for invalid or incomplete data to enter the database.

Additionally, this project strengthened my ability to communicate technical improvements through documentation and organized code.

## Reflection

Working on this enhancement helped me better understand how important database design is to the overall quality of a software application.

Earlier in my education, I viewed a database primarily as a place to store information. Through this project, I learned that database design directly affects application performance, maintainability, scalability, and security.

One of the biggest challenges was ensuring that changes to the database model remained compatible with the frontend application and API endpoints. Updating schemas required testing CRUD operations carefully to verify that information continued to flow correctly throughout the application.

Another challenge was improving validation without breaking existing functionality. This required reviewing both the backend controllers and Mongoose schemas to ensure consistent behavior.

Overall, this enhancement strengthened my confidence working with MongoDB, Mongoose, REST APIs, and backend application architecture. It also reinforced the importance of planning database structures carefully before implementation.

I believe these skills will be valuable in future software engineering, quality assurance, or data analytics roles where reliable data management is essential.
